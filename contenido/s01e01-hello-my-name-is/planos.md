# Episodio 01 — Lista de planos (ilustraciones para Google Flow)

**Cómo usarla**
1. En Flow, adjunta como referencia (ingredientes) las hojas de los personajes que salen en el plano:
   `characters/miss-maya/hoja-ref.png`, `characters/leo/hoja-ref.png`, `characters/mia/hoja-ref.png`
   (o las hojas completas de `characters/_hojas-origen/`).
2. Copia el **prefijo común** + el prompt del plano. Formato **16:9**, máxima resolución.
3. Guarda cada imagen como `contenido/s01e01-hello-my-name-is/planos/PNN.png` (P01, P02…).
4. Si una imagen sale con texto, logotipos o personajes distintos, repítela: no la corrijas a mano.

**Prefijo común (pegar delante de cada prompt)**
```
Original premium 3D animated series, cinematic feature-film quality, warm soft lighting, vibrant
harmonious colors. Use the supplied character references and keep their exact faces, hairstyles, outfits
and colors. Adult characters. 16:9 wide shot with empty space in the upper third for on-screen text.
No text, no letters, no logos, no watermarks.
```
